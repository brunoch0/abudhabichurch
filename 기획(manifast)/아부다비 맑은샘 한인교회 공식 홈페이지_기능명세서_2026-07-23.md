## 1. 프로젝트 개요
---
### 한 줄 정의
아부다비 맑은샘 한인교회 홈페이지

### 제품 목표
기존 교인에게 예배·설교·주보·일정 정보를 모바일 중심으로 제공하고, 아부다비 거주·이주 한인 방문자에게 교회 소개와 문의·참여 경로를 제공한다. 비개발자인 교회 담당자가 코드 수정 없이 콘텐츠와 운영 데이터를 관리하고, 시스템·도메인·데이터를 교회에 인수인계할 수 있는 공식 홈페이지를 만든다.

### 배경
아부다비 소재 한인교회는 설교 영상, 주보, 공지, 일정, 부서 활동 등 분산된 정보를 한 곳에서 전달할 공식 채널이 필요하다. Instagram과 YouTube 채널을 보유하고 있으며, 한국어 중심 사이트와 간단한 영어 안내 페이지를 통해 검색 유입과 현지 방문자 안내를 강화한다.

### 사용자 문제
기존 교인은 최신 주보·설교·일정·교회 소식을 빠르게 확인하기 어렵고, 새가족과 방문자는 예배 시간·위치·문의 방법을 검색 후 즉시 파악할 공식 안내 채널이 부족하다. 교회 담당자는 비개발자도 여러 콘텐츠를 직접 관리하고 행사 신청·문의 접수를 놓치지 않을 운영 도구가 필요하다.

### 해결 방안
모바일 우선의 공식 홈페이지에서 교회소개, 예배와 말씀, 공동체, 교회소식, 문의를 제공하고 YouTube·Instagram 콘텐츠를 연결한다. 관리자 화면에서 배너, 페이지, 게시판, 설교, 주보, 일정, 신청, 문의를 관리하며, 1차에는 파일형 주보와 기본 콘텐츠 운영을 제공하고 2차에 템플릿형 주보와 신청·부서·앨범·Instagram 연동을 확장한다.

### 차별점
교회 운영자가 코드를 수정하지 않고 주보·설교·일정·행사 접수까지 관리할 수 있도록 쉬운 관리자 화면과 인수인계 가능한 데이터·도메인 운영 구조를 제공한다. 맑은샘 모티프의 밝은 블루·화이트 기반 모던 디자인과 한국어 중심·영어 간단 안내 페이지를 결합해 현지 한인 검색 유입과 모바일 정보 확인을 함께 지원한다.

### 타겟 사용자
기존 교인은 모바일에서 주보, 설교 영상, 교회 일정, 공지와 앨범을 확인하는 한국어 사용자다. 새가족·방문자는 아부다비 이주·파견 전후에 아부다비 한인교회, 아부다비 교회, UAE 한인교회 등을 검색해 유입하며 예배 안내, 위치, 연락처, 새가족 절차를 확인한다. 교회 담당자는 콘텐츠·행사·문의·신청자를 관리하는 비개발자이며 최고관리자와 편집자 역할로 구분된다.

### 사용자 시나리오
교인은 홈에서 최신 설교·이번 주 주보·다가오는 일정을 확인하고 필요한 콘텐츠 상세 화면으로 이동한다. 방문자는 검색 결과나 영어 안내 페이지에서 예배 시간, 주소, 오시는 길, 문의 방법을 확인하고 문의를 남긴다. 관리자는 관리자 화면에서 배너와 게시물을 등록하고, 일정·주보를 발행하며, 신청·문의 알림을 확인한 뒤 운영 데이터를 인수인계한다.

### 핵심 지표
월간 방문자 수와 검색 유입 비중, 모바일 방문 비중, 설교 영상·주보 조회 수, 문의 접수 수, 행사 신청 완료 수를 측정한다. 콘텐츠 최신성은 주보와 공지의 정시 발행 여부, 운영성은 관리자 콘텐츠 등록 성공률과 인수인계 후 자체 운영 가능 여부로 확인한다.

### 리스크
도메인, 교회 소개 문구, 인사말, 연락처, 이메일, 주소는 미정으로 플레이스홀더를 사용하고 공개 전 실제 정보로 교체해야 한다. YouTube·Instagram API 정책과 권한 변경으로 자동 연동이 제한될 수 있으므로 관리자 링크·피드 수동 등록 경로를 제공한다. 문의와 신청 정보에는 개인정보가 포함되므로 접근 권한, 보관 기간, 이메일 발송 설정을 운영 정책으로 확정해야 한다.

## 1. 공식 홈페이지 탐색과 교회 안내
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

방문자와 기존 교인이 모바일·데스크톱에서 홈, 교회소개, 영어 간단 안내, 예배 안내, 오시는 길을 쉽게 탐색하는 영역이다. 홈은 최신 콘텐츠와 핵심 안내를 요약하고, 교회소개는 인사말·비전·섬기는 사람들·새가족 안내를 제공한다. 연락처·주소·소개 문구가 확정되기 전에는 관리자 교체용 플레이스홀더를 사용하며 일반 교인 회원 기능은 포함하지 않는다.

**수용 기준:**
```
1. ○ 홈에서 예배시간, 최신 설교, 이번 주 주보, 공지, 일정, Instagram 미리보기, 오시는 길을 확인할 수 있다.
2. ○ 교회소개에서 인사말, 교회 비전, 섬기는 사람들, 예배 안내, 오시는 길, 새가족 안내를 확인할 수 있다.
3. ○ 영어 안내 페이지에서 교회 소개, 예배시간, 주소, 연락처를 제공한다.
```


### 1.1 홈 요약 콘텐츠
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

방문자와 기존 교인이 홈에서 교회 핵심 정보와 최신 콘텐츠를 한 화면에서 확인하는 기능이다. 관리자 교체형 슬라이드 배너, 예배시간 카드, 최신 설교, 금주의 주보, 공지 3~5건, 다가오는 일정, Instagram 피드 미리보기, 지도·주소를 카드형으로 노출한다. 모바일 우선의 밝은 블루·화이트 디자인을 적용하며 각 요약 영역은 해당 상세 페이지로 이동하고 Instagram 자동 연동이 어려우면 관리자가 수동 피드를 등록한다.


#### 1.1.1 홈 콘텐츠 요약 노출

방문자는 홈에서 예배시간, 최신 설교 1건, 최신 주보, 공지 3~5건, 다가오는 일정, Instagram 피드, 지도·주소를 확인한다. 각 영역은 관리자 설정 순서와 공개 상태를 따르며 선택 시 해당 상세 또는 외부 원문으로 이동한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


#### 1.1.2 관리형 히어로 배너

관리자는 이미지, 제목, 설명, 연결 주소, 노출 순서, 공개 기간을 가진 히어로 배너를 등록한다. 방문자는 모바일·데스크톱에서 슬라이드 배너를 보고 연결된 안내 화면으로 이동한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


### 1.2 교회소개와 예배 안내
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

방문자가 교회의 인사말, 비전·소개, 섬기는 사람들, 예배별 시간·장소, 새가족 등록 절차를 확인하는 기능이다. 주소·연락처·인사말 등 미확정 정보는 관리자 교체용 플레이스홀더로 표시하고, 오시는 길에는 지도와 주소 복사 동작을 제공한다. 한국어 소개와 함께 영어 한 페이지에서 교회 소개, 예배시간, 주소, 연락처를 제공하며 모든 텍스트는 관리자 화면에서 수정한다.


#### 1.2.1 예배시간과 오시는 길 확인

방문자는 예배별 시간·장소, 지도, 주소, 연락처를 교회소개 화면에서 확인하고 주소를 복사할 수 있다. 실제 정보가 비어 있으면 관리자용 플레이스홀더로 표시해 공개 전 교체가 필요함을 알린다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


#### 1.2.2 영어 안내 페이지 조회

영어 사용 방문자는 단일 영어 안내 페이지에서 교회 소개, 예배시간, 주소, 연락처를 확인한다. 한국어 콘텐츠 게시판과 전체 메뉴 번역은 이 동작에 포함하지 않는다.
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중

## 2. 콘텐츠 발행과 아카이브
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

교회 담당자가 공지, 설교 영상, 주보, 부서 게시물, 앨범을 발행하고 이용자가 목록·검색·상세 화면에서 확인하는 콘텐츠 영역이다. 사진·글 게시판과 YouTube 영상 메타데이터, 주차별 주보 아카이브를 포함한다. 1차는 파일형 주보와 설교·공지 중심으로 제공하고 템플릿형 주보·부서·앨범은 2차 범위다.

**수용 기준:**
```
1. ○ 관리자가 공지와 사진·글 게시물을 등록·수정·삭제하고 공개 상태를 관리할 수 있다.
2. ○ 이용자가 설교를 카테고리와 검색으로 찾고 상세 화면에서 재생할 수 있다.
3. ○ 이용자가 최신 주보와 과거 주보를 확인하거나 파일을 내려받을 수 있다.
```


### 2.1 카테고리형 사진·글 게시판
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

관리자가 공지와 부서별 사진·글 게시판의 카테고리 및 게시물을 관리하고 이용자가 카드형 목록과 상세 화면에서 읽는 기능이다. 게시물은 제목, 리치 에디터 본문, 다중 이미지, YouTube 링크 임베드를 지원하며 관리자는 부서·게시판 카테고리를 추가·수정·삭제할 수 있다. 부서별 소개·게시판과 행사별 사진 앨범은 2차에 제공하며 앨범은 사진 중심 카드 목록으로 구분한다.


#### 2.1.1 게시판 카테고리 관리

관리자는 부서 또는 게시판 카테고리의 이름, 소개, 정렬 순서, 공개 여부를 생성·수정·삭제한다. 삭제 전 연결 게시물의 이동 또는 비공개 처리 방식을 확인해 콘텐츠 손실을 방지한다.
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중


#### 2.1.2 사진·글 게시물 발행

관리자는 제목, 리치 에디터 본문, 다중 이미지, YouTube 링크, 카테고리, 공개 상태를 입력해 게시물을 발행한다. 방문자는 카드형 목록과 상세 화면에서 본문·이미지·삽입 영상을 확인한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


#### 2.1.3 행사별 앨범 열람

방문자는 행사명, 행사일, 설명, 대표 이미지로 구분된 사진 앨범 목록과 상세 갤러리를 확인한다. 관리자는 앨범을 사진 중심 게시물로 발행하며 2차 제공 범위로 관리한다.
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중


### 2.2 설교 영상 아카이브
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

이용자가 주일예배, 수요예배, 특별집회 등 카테고리별 설교 영상을 목록·검색·상세 화면에서 확인하고 재생하는 기능이다. 영상에는 제목, 본문, 설교자, 날짜, YouTube 링크와 썸네일을 관리하며 홈에는 최신 영상을 노출한다. 자동 수집이 불가한 경우 관리자가 영상 링크와 메타데이터를 직접 등록한다.


#### 2.2.1 설교 영상 검색과 재생

방문자는 설교 제목, 본문, 설교자, 날짜를 기준으로 검색하거나 예배 카테고리별 목록에서 영상을 선택한다. 상세 화면은 YouTube 임베드 재생과 영상 메타데이터를 제공한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


#### 2.2.2 설교 영상 등록

관리자는 YouTube 링크와 제목, 본문, 설교자, 날짜, 카테고리, 공개 상태를 입력해 설교 영상을 등록한다. 채널 자동 수집 결과를 수정하거나 자동 수집이 불가능할 때 직접 등록할 수 있다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


### 2.3 파일형 주보 아카이브
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

이용자가 최신 주보를 우선 확인하고 주차별 목록에서 지난 주보를 열람하거나 PDF 파일을 내려받는 기능이다. 관리자는 주차, 발행일, 제목, 대표 이미지, PDF 파일을 등록하고 최신 노출 여부를 관리한다. 1차 MVP의 주보 방식이며 웹 주보 편집은 포함하지 않는다.


#### 2.3.1 최신 주보와 지난 주보 열람

방문자는 최신 주보를 기본으로 확인하고 주차별 아카이브에서 지난 주보를 선택해 PDF를 열람하거나 내려받는다. 관리자는 주차와 발행일을 기준으로 최신 주보를 지정한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


### 2.4 템플릿형 웹 주보
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중

관리자가 고정된 주보 양식 안에서 각 섹션의 내용만 입력해 주일 주보를 발행하는 기능이다. 양식은 헤더(호수·날짜·연도 표어·성경구절), 주일예배 순서 테이블, 예배안내 테이블, 맑은샘소식·광고 목록, 맑은샘모임·헌금안내 자유 텍스트, 푸터(연락처·담임목사)로 고정 구성되며 전체 레이아웃과 디자인은 변경하지 않는다. 관리자는 각 섹션별 입력 폼에서 텍스트와 반복 행만 수정하며, 지난 주보를 복사해 새 주보를 만들 수 있고 발행 전 미리보기·인쇄·PDF 내려받기를 제공한다. 파일형 주보와 병행 운영하며 2차 범위로 제공한다.


#### 2.4.1 웹 주보 발행과 복사

관리자는 주보 편집 화면에서 호수와 날짜를 입력하고 섹션별 내용을 수정한 뒤 발행한다. 지난 주보를 복사해 새 주보를 생성할 수 있고, 발행 전 미리보기를 통해 화면 구성을 확인한다. 발행된 주보는 일반 방문자 화면에 짦범위 주보로 노출되고 PDF 내려받기와 인쇄용 화면을 제공한다.
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중


#### 2.4.2 헤더 정보 입력

관리자는 호수(예: 제2026-29호), 날짜(예: 2026. 7. 19), 주차 표기(예: 성령강림 후 제8주), 연도 표어, 성경구절과 출처를 입력 필드에 입력한다. 헤더 영역의 로고와 배경 이미지는 고정이며 텍스트 필드만 수정한다. '이웃과 함께하는 맑은샘모임'과 '헌금안내' 영역은 같은 화면에서 이모지·연락처를 포함한 자유 텍스트로 편집하며 레이아웃 내 위치는 고정된다.
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중


#### 2.4.3 주일예배 순서 테이블 편집

관리자는 주일예배 순서를 행 단위로 관리하며, 각 행에 순서명(한국어), 내용(한국어, 예: 찬송 번호·제목·설교 제목), 영어 순서명을 입력한다. 행을 추가·삭제하거나 드래그로 순서를 바꾼 수 있으며, 지난 주보 복사 시 행이 모두 복사된다.
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중


#### 2.4.4 예배안내 테이블 편집

관리자는 예배 종류(주일예배, 다음세대예배, 셈예배, 새벽기도 등)별로 시간, 장소(예: ST.ANDREW 신관칔펙, 유튜브)를 입력하고 행을 추가·삭제할 수 있다. 테이블 콼럼 순서는 고정되며 시간과 장소만 편집한다.
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중


#### 2.4.5 광고 목록 편집

관리자는 광고 단락을 번호 목록 형태로 관리하며 제목과 세부 내용(본문)을 입력한다. 항목을 추가·삭제하거나 순서를 조정할 수 있으며, 입력된 순서대로 자동 번호매김되어 화면에 노출된다.
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중

## 3. 일정과 활동 참여
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

교회 담당자가 교회 일정과 성경학교 등 활동 신청 이벤트를 관리하고, 방문자와 교인이 일정을 확인하거나 비회원으로 신청하는 영역이다. 일정은 월간 캘린더와 목록으로 제공하며 홈에 다가오는 일정을 요약한다. 활동 신청과 이메일 통보는 2차 범위이며 일반 사용자 계정·로그인은 포함하지 않는다.

**수용 기준:**
```
1. ○ 관리자가 제목, 날짜·기간, 장소, 설명, 카테고리를 포함한 일정을 등록하고 수정할 수 있다.
2. ○ 이용자가 월간 캘린더와 목록에서 일정을 확인하고 홈에서 다가오는 일정을 볼 수 있다.
3. ○ 비회원이 필수 연락처 정보와 이벤트별 입력 항목을 작성해 신청하고 접수 결과를 이메일로 받을 수 있다.
```


### 3.1 교회 일정 캘린더
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

이용자가 교회 일정을 월간 캘린더와 목록 화면에서 확인하고 홈에서 다가오는 일정을 보는 기능이다. 관리자는 제목, 시작·종료 일시, 장소, 설명, 카테고리를 등록하고 일정 기간을 설정한다. 일정 상세 화면에서는 행사 정보를 제공하며 외부 개인 캘린더 동기화는 포함하지 않는다.


#### 3.1.1 월간 일정과 목록 조회

방문자는 월간 캘린더와 날짜순 목록에서 교회 일정을 확인하고 일정 상세에서 제목, 기간, 장소, 설명, 카테고리를 읽는다. 홈에는 현재 시점 이후의 다가오는 일정만 요약해 표시한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


#### 3.1.2 일정 등록과 수정

관리자는 제목, 시작·종료 일시, 장소, 설명, 카테고리, 공개 상태를 입력해 일정을 등록·수정·삭제한다. 종료일이 시작일보다 빠른 값은 저장하지 않으며 기간 일정은 캘린더 전체 기간에 표시한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


### 3.2 활동 신청 접수
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중

비회원이 성경학교 등 관리자가 만든 이벤트에 이름, 연락처, 이메일과 이벤트별 맞춤 입력 항목을 작성해 신청하는 기능이다. 이벤트마다 설명, 이미지, 신청 기간, 정원, 필수 입력 항목을 설정하며 마감 상태에서는 신규 신청을 받지 않는다. 신청 완료 시 신청자와 관리자에게 이메일을 발송하고, 관리자는 명단 조회·CSV 내려받기·마감 처리를 수행하며 2차 범위로 제공한다.


#### 3.2.1 비회원 활동 신청

방문자는 신청 기간 중인 이벤트에서 이름, 연락처, 이메일과 관리자가 설정한 맞춤 필드를 작성해 신청한다. 필수 항목 누락, 마감일 경과, 정원 초과 시 신청을 완료할 수 없다.
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중


#### 3.2.2 신청 이메일과 명단 내려받기

신청이 완료되면 신청자에게 접수 확인 이메일을, 관리자에게 새 신청 알림 이메일을 발송한다. 관리자는 이벤트별 신청자와 맞춤 입력값을 조회하고 CSV로 내려받거나 이벤트를 마감 처리한다.
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중

## 4. 문의와 새가족 전환

방문자와 새가족이 전 페이지의 문의 톡 또는 문의 화면에서 교회 담당자에게 문의하고, 담당자가 접수와 답변 상태를 관리하는 영역이다. 카카오톡 채널 또는 WhatsApp 외부 링크를 함께 노출할 수 있다. 실시간 채팅 기능은 범위에서 제외하며 폼 접수와 알림 중심으로 제공한다.

**수용 기준:**
```
1. ○ 비회원이 이름, 연락처, 문의 내용을 작성해 문의를 접수할 수 있다.
2. ○ 문의 접수 시 관리자 이메일 알림이 발송되고 관리자 화면에서 답변 상태를 관리할 수 있다.
3. ○ 관리자가 문의 톡에 카카오톡 채널 또는 WhatsApp 링크를 선택적으로 설정할 수 있다.
```


### 4.1 문의 접수

방문자와 새가족이 전 페이지의 플로팅 문의 톡 또는 문의 페이지에서 이름, 연락처, 문의 내용을 작성해 담당자에게 접수하는 기능이다. 비회원도 사용할 수 있으며 접수 완료 안내와 관리자 이메일 알림을 제공한다. 관리자는 문의 목록에서 미처리·답변중·완료 상태를 관리하고 카카오톡 채널 또는 WhatsApp 외부 링크를 선택적으로 노출하며 실시간 상담은 포함하지 않는다.


#### 4.1.1 플로팅 문의 톡 접수

방문자는 모든 페이지의 플로팅 문의 톡 또는 문의 화면에서 이름, 연락처, 문의 내용을 작성해 접수한다. 접수 후 완료 안내를 표시하고 관리자 지정 이메일로 알림을 보낸다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


#### 4.1.2 문의 상태와 외부 메신저 안내

관리자는 문의 목록에서 접수 시각, 연락처, 내용, 처리 상태를 확인하고 미처리·답변중·완료로 변경한다. 방문자에게는 설정된 카카오톡 채널 또는 WhatsApp 링크를 함께 제공할 수 있다.
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중

## 5. 관리자 운영과 권한
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

최고관리자와 편집자가 비개발자용 관리자 화면에서 사이트 콘텐츠와 운영 데이터를 관리하는 영역이다. 배너, 고정 페이지, 게시판·카테고리, 설교, 주보, 일정, 신청, 문의, 앨범을 관리하고 최근 현황을 대시보드에서 확인한다. 사용자 역할은 최고관리자와 편집자로 제한하며 교인용 회원 관리·요람은 포함하지 않는다.

**수용 기준:**
```
1. ○ 최고관리자와 편집자가 관리자 계정으로 로그인하고 역할에 맞는 관리 메뉴를 사용할 수 있다.
2. ○ 관리자가 코드 수정 없이 배너, 고정 페이지, 콘텐츠, 일정, 문의를 관리할 수 있다.
3. ○ 대시보드에서 최근 문의, 최근 신청, 게시물 현황을 확인할 수 있다.
```


### 5.1 관리자 로그인과 역할 권한
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

최고관리자와 편집자가 관리자 계정으로 로그인하고 역할에 맞는 관리 기능을 사용하는 기능이다. 최고관리자는 계정·권한과 전체 콘텐츠를 관리하며 편집자는 허용된 콘텐츠 운영 업무를 수행한다. 일반 교인 회원가입과 로그인은 제공하지 않는다.


#### 5.1.1 관리자 역할별 접근

최고관리자는 관리자 계정과 전체 메뉴를 관리하고 편집자는 허용된 콘텐츠 메뉴만 사용한다. 비로그인 사용자는 관리자 화면과 개인정보가 포함된 신청·문의 정보를 볼 수 없다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


### 5.2 운영 대시보드
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중

관리자가 로그인 후 최근 문의, 최근 신청, 게시물 현황을 한 화면에서 확인하고 관련 관리 화면으로 이동하는 기능이다. 각 항목은 최신 순으로 요약하며 미처리 문의와 진행 중 신청을 우선 보여준다. 교회 인수인계를 위해 도메인, 관리자 계정, 콘텐츠·미디어 데이터, 이메일 설정의 점검 항목을 함께 제공하며 상세 통계 분석은 포함하지 않는다.


### 5.3 사이트 콘텐츠 관리
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

관리자가 배너, 고정 페이지 텍스트, 게시판·카테고리, 게시물, 설교, 주보, 일정, 신청 이벤트·신청자, 문의, 앨범을 코드 수정 없이 관리하는 기능이다. 입력 화면은 비개발자가 이해할 수 있는 한국어 안내와 미리보기 중심으로 구성한다. 실제 공개 정보와 미정 플레이스홀더를 구분해 관리한다.


#### 5.3.1 콘텐츠 관리 화면

관리자는 배너, 고정 페이지, 게시판·카테고리, 게시물, 설교, 주보, 일정, 신청, 문의, 앨범을 목록·등록·수정·삭제 화면에서 관리한다. 입력 항목에는 한국어 도움말, 공개 상태, 저장·미리보기 동작을 제공해 비개발자가 운영한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


#### 5.3.2 운영 데이터 구조

사용자·권한은 관리자, 역할 테이블로 관리하고 콘텐츠는 페이지, 배너, 카테고리, 게시물, 미디어, 설교, 주보 테이블로 분리한다. 운영 데이터는 일정, 신청이벤트, 신청필드, 신청자, 문의 테이블로 관리하며 게시물·앨범·신청자·문의에는 생성일, 수정일, 공개 또는 처리 상태를 기록한다. 미디어는 소유 항목과 연결하고 신청자·문의의 개인정보는 관리자 역할을 가진 사용자만 조회한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

## 6. 검색 노출과 외부 채널 연동
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

검색 방문자가 교회 홈페이지를 찾고 YouTube·Instagram의 최신 콘텐츠를 사이트에서 확인하는 영역이다. 페이지별 검색 메타데이터, 공유 미리보기, 사이트맵, 교회 구조화 데이터를 제공하며 검색 도구 등록이 가능한 구조를 포함한다. 외부 API 제한 시 관리자 수동 등록으로 운영을 이어갈 수 있어야 한다.

**수용 기준:**
```
1. ○ 주요 페이지에 검색 메타 태그와 공유용 OG 태그를 설정할 수 있다.
2. ○ sitemap.xml과 Church 또는 LocalBusiness 구조화 데이터를 제공한다.
3. ○ YouTube 최신 영상과 Instagram 피드를 자동 또는 관리자 수동 등록 방식으로 노출할 수 있다.
```


### 6.1 검색 노출 설정
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

관리자가 주요 페이지의 제목, 설명, 공유 이미지 등 검색·공유 정보를 관리하고 검색엔진이 사이트를 수집할 수 있도록 하는 기능이다. sitemap.xml, robots 설정, Church 또는 LocalBusiness 구조화 데이터를 제공하며 아부다비 한인교회, 아부다비 교회, UAE 한인교회, 아랍에미리트 한인교회를 중심 키워드로 반영한다. 네이버와 구글 서치콘솔에 등록 가능한 소유 확인 구조를 포함한다.


#### 6.1.1 검색과 공유 메타데이터 제공

각 주요 페이지는 검색 제목, 설명, 대표 이미지의 메타데이터와 OG 태그를 제공한다. 시스템은 sitemap.xml, robots 설정, Church 또는 LocalBusiness 구조화 데이터를 생성해 네이버·구글 서치콘솔 등록을 지원한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중


### 6.2 YouTube 설교 연동
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

공식 YouTube 채널의 최신 설교 영상을 홈과 설교 아카이브에 노출하는 기능이다. 채널 자동 수집을 우선 지원하되 API 권한·정책 문제 시 관리자가 YouTube 링크를 직접 등록하는 대체 방식을 제공한다. 영상 재생은 YouTube 임베드를 사용하며 사이트 내 별도 영상 저장은 포함하지 않는다.


#### 6.2.1 최신 설교 영상 동기화와 수동 전환

시스템은 공식 YouTube 채널의 최신 공개 영상을 정해진 주기로 확인해 설교 아카이브와 홈 최신 설교 영역에 반영한다. 자동 수집 권한이 없거나 수집이 실패하면 관리자가 YouTube 링크와 제목, 설교자, 날짜를 등록해 같은 노출 영역을 운영한다. 비공개·삭제된 영상은 재생 가능한 최신 공개 영상으로 교체하거나 관리자에게 확인이 필요함을 표시한다.
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중
