# 아부다비 맑은샘 한인교회 — 개발 로드맵

> Phase 1 = 현재 라이브 상태 (abudhabikoreanchurch.vercel.app)
> 각 Phase 끝의 "교회 확인 질문"으로 피드백 받으면서 진행

## Phase 1 — 공개 사이트 (✅ 완료, 2026-07-23)
- 홈, 교회소개(인사말/섬기는분들/예배안내/오시는길/새가족), English
- 설교 영상(유튜브 연동), 주보 아카이브, 공지사항, 교회 일정 캘린더
- 문의 폼 + 플로팅 문의 톡 (DB 접수)
- 모바일 최적화, SEO 기본

**남은 마감 작업:** 인사말·소개 확정 문구 반영, 교회 사진 배너 교체, sitemap/OG 마무리

## Phase 2 — 운영 시스템 (교회가 직접 관리)
목표: 교회 담당자가 코드 없이 콘텐츠를 직접 올리는 구조

| 기능 | 내용 |
|------|------|
| 관리자 로그인 | 최고관리자/편집자 2단계 권한 |
| 대시보드 | 미처리 문의, 최근 게시물 현황 |
| 콘텐츠 관리 | 설교(유튜브 자동수집+수동), 주보 업로드, 공지, 일정, 배너, 고정페이지 문구 수정 |
| 문의 관리 | 목록·처리상태(미처리/답변중/완료) + **이메일 알림** (Resend) |
| 유튜브 자동 동기화 | 채널 RSS 주기 수집 → 새 설교 자동 등록 |

**교회 확인 질문:**
- 홈페이지 관리는 누가 하시게 되나요? (담당자 1~2명 지정)
- 문의 알림 받을 이메일 주소는?
- 주보는 매주 파일(PDF/이미지)로 올리는 방식이 편하신가요?

## Phase 3 — 참여 기능 (교인·방문자 상호작용)
목표: 신청·참여가 온라인으로 이루어지는 교회

| 기능 | 내용 |
|------|------|
| 활동 신청 | 성경학교 등 이벤트 신청 폼(비회원 가능, 이벤트별 맞춤 입력항목, 정원·마감) |
| 신청 이메일 통보 | 신청자 확인 메일 + 관리자 알림, 명단 CSV 다운로드 |
| 부서(공동체) 페이지 | 유치부/청소년부/청년부 등 부서별 소개+사진·글 게시판, 부서는 관리자가 추가/삭제 |
| 교회 앨범 | 행사별 사진 갤러리 |
| 인스타 피드 연동 | 홈에 최신 피드 노출 |

**교회 확인 질문:**
- 부서 구성이 어떻게 되나요? (부서 이름·담당자)
- 신청 받는 행사가 연간 어떤 것들이 있나요? (성경학교, 수련회 등)
- 행사 사진은 누가 찍고 모아두시나요?

## Phase 4 — 회원·심화 기능 (수요 확인 후)
목표: 교인 전용 공간 — **실수요 확인되면 진행** (개인정보 관리 부담이 생기므로 신중히)

| 기능 | 내용 |
|------|------|
| 교인 회원가입/로그인 | 관리자 승인제 (아무나 가입 X) |
| 교인 전용 콘텐츠 | 교인 전용 게시판, 중보기도 요청, 셀 모임 자료 |
| 템플릿형 웹 주보 | 주보 양식 그대로 웹에서 입력→발행, 지난 주보 복사, PDF 출력 |
| 온라인 헌금 안내 | 계좌 안내 페이지 (결제 기능 아님) |
| 푸시/알림 | 카카오톡 채널 연동 등 |

**교회 확인 질문:**
- 교인만 봐야 하는 콘텐츠가 실제로 있나요? (없으면 회원가입 불필요)
- 주보를 웹에서 직접 만드는 것과 파일 업로드 중 어느 쪽이 편하신가요?

## 진행 원칙
- 각 Phase 완료 시 교회 검토 → 피드백 반영 → 다음 Phase
- 회원가입(Phase 4)은 수요 확인 전에 만들지 않음 — 운영 부담만 늘어남
- 콘텐츠가 계속 올라오는 게 사이트 생명 — Phase 2(관리자)가 최우선
