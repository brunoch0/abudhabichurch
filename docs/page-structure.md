## 4. MVP 빌드 순서 (제안)
1. 프로젝트 셋업 (Next.js + Supabase + 스키마) + 글로벌 레이아웃/디자인 시스템
2. 고정 페이지 (홈 뼈대, 교회소개 5종, EN, 오시는 길)
3. 콘텐츠 모듈 (설교 → 주보 → 공지 → 일정)
4. 문의 (폼 + 이메일 알림 + 플로팅 버튼)
5. 관리자 (로그인 → 대시보드 → 각 관리 화면)
6. SEO + 홈 조립 + 로컬 검증 → 배포
