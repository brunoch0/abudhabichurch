## 프롬프트

아래 요구사항으로 "아부다비 맑은샘 한인교회" 공식 홈페이지의 기능명세서를 작성해줘.

### 1. 프로젝트 개요
- **프로젝트명:** 아부다비 맑은샘 한인교회 공식 홈페이지
- **소개:** UAE 아부다비 소재 한인교회. 예배·설교 콘텐츠 아카이브, 교회 소식 전달, 새가족 유입, 활동(성경학교 등) 신청 접수가 목적
- **타겟 사용자:**
  1. 기존 교인 — 주보, 설교 영상, 일정, 앨범 확인
  2. 새가족/방문자 — 아부다비 이주·파견 한인이 검색으로 유입 ("아부다비 한인교회", "아부다비 교회", "UAE 한인교회") → 예배 안내, 오시는 길, 문의
  3. 관리자(교회 담당자, 비개발자) — 모든 콘텐츠를 코드 수정 없이 관리
- **언어:** 한국어 기본, 영어 간단 소개 페이지 1개 (About, 예배시간·주소·연락처)
- **최종 목표:** 시스템 빌드 후 교회 측에 운영 인수인계 (도메인·데이터 포함). 비개발자가 유지보수 가능한 관리자 구조가 필수
- **기존 채널 (연동 대상):**
  - Instagram: @abudhabi_korean_church
  - YouTube: @_adkmc737 (아부다비 맑은샘 한인교회_ADKMC)

### 2. 사이트 구조 (IA)

**① 홈 (메인)**
- 메인 히어로 배너 (관리자 교체 가능, 슬라이드)
- 예배시간 요약 카드
- 최신 설교 영상 (유튜브 최신 영상 자동 표시)
- 금주의 주보 바로가기
- 공지사항 최신 3~5건
- 다가오는 일정 (캘린더 요약)
- 인스타그램 피드 미리보기
- 오시는 길 (지도 + 주소)

**② 교회소개**
- 인사말 (담임목사)
- 교회 비전/소개
- 섬기는 사람들
- 예배 안내 (예배별 시간·장소)
- 오시는 길 (구글맵 임베드, 주소 복사)
- 새가족 안내 (등록 절차 + 새가족 문의 유도)

**③ 예배와 말씀**
- 설교 영상: 유튜브 연동, 카테고리(주일예배/수요예배/특별집회 등)별 목록 + 상세 재생, 제목·본문·설교자·날짜 메타데이터, 검색
- 주보: 주차별 아카이브, 최신 주보가 기본 노출

**④ 공동체 (다음세대·부서)**
- 부서별 페이지 (사진+글 카테고리 게시판): 유치부/초등부/중고등부/청년부/선교회 등 — 부서 자체를 관리자가 추가·삭제 가능해야 함
- 각 부서: 소개 + 사진·글 게시물 목록

**⑤ 교회소식**
- 공지사항 게시판
- 교회 일정 (월간 캘린더 뷰 + 목록 뷰)
- 교회 앨범 (사진 갤러리, 행사별 묶음)
- 활동 신청: 성경학교 등 이벤트 신청 페이지

**⑥ 문의**
- 문의 폼 + 플로팅 "문의 톡" 버튼 (전 페이지)

### 3. 핵심 기능 명세 대상

**A. 카테고리별 콘텐츠 게시판 (사진+글)**
- 관리자가 카테고리(부서/게시판)를 자유롭게 생성·수정·삭제
- 게시물: 제목, 본문(리치 에디터), 다중 이미지 업로드, 유튜브 링크 임베드
- 프론트: 카드형 목록 + 상세 페이지

**B. 유튜브·인스타 연동**
- 유튜브: 채널 최신 영상 자동 수집(또는 관리자가 링크 등록) → 설교 페이지·홈에 노출
- 인스타: 최신 피드 홈 노출 (API 제약 시 관리자 수동 등록 폴백 포함해서 명세)

**C. 주보 만들기 (핵심 차별 기능)**
- 관리자가 템플릿에 내용 입력(예배 순서, 찬송, 성경 본문, 광고/소식, 기도제목) → 웹 주보 페이지 자동 생성
- 모바일 최적화 웹 주보 + PDF 다운로드(또는 인쇄용 뷰)
- 주차별 아카이브, 지난 주보 복사해서 새 주보 만들기
- PDF 파일 직접 업로드 방식도 병행 지원

**D. 일정 관리**
- 관리자가 일정 등록 (제목, 날짜/기간, 장소, 설명, 카테고리)
- 프론트: 월간 캘린더 + 다가오는 일정 목록, 홈 노출

**E. 활동 신청 + 이메일 통보**
- 관리자가 신청 이벤트 생성 (제목, 설명, 이미지, 신청 기간, 정원, 커스텀 입력 필드 — 예: 자녀 이름/나이)
- 비회원도 신청 가능 (이름, 연락처, 이메일 필수)
- 신청 완료 시: 신청자에게 확인 이메일 자동 발송 + 관리자에게 알림 이메일
- 관리자: 신청자 명단 조회, 엑셀(CSV) 다운로드, 마감 처리

**F. 문의 톡**
- 비회원 포함 누구나 관리자에게 문의 (플로팅 버튼 → 문의 폼: 이름, 연락처, 내용)
- 접수 시 관리자 이메일 알림, 관리자 페이지에서 문의 목록·답변 상태 관리
- 카카오톡 채널/WhatsApp 링크 버튼 병기 옵션

**G. 관리자 기능 (Admin)**
- 로그인 (관리자 계정, 역할: 최고관리자/편집자)
- 대시보드: 최근 문의, 최근 신청, 게시물 현황
- 관리 대상: 배너, 페이지 텍스트(인사말·소개·예배안내), 게시판/카테고리, 게시물, 설교 영상, 주보, 일정, 신청 이벤트+신청자, 문의, 앨범
- 비개발자 기준의 쉬운 UI (인수인계 전제)

**H. SEO / 검색 유입**
- 페이지별 메타 태그, OG 태그, sitemap.xml, 구조화 데이터(Church/LocalBusiness schema)
- 타겟 키워드: 아부다비 한인교회, 아부다비 교회, UAE 한인교회, 아랍에미리트 한인교회
- 네이버·구글 서치콘솔 등록 가능 구조

### 4. 디자인 방향
- 참고 사이트: 새샘교회(saesaem.com) 수준의 깔끔한 구조. 단, 국내 교회 빌더 특유의 올드한 느낌은 배제하고 모던·미니멀하게
- "맑은샘" 모티프: 밝고 따뜻한 톤, 물/샘을 연상시키는 블루+화이트 계열
- 모바일 퍼스트 (교인 대부분 모바일 접속)

### 5. 우선순위
- **MVP (1차):** 홈, 교회소개, 설교 영상(유튜브), 주보(파일 업로드 방식), 공지, 일정, 오시는 길, 문의 폼, 관리자 기본 CRUD, SEO
- **2차:** 주보 템플릿 빌더, 활동 신청+이메일 통보, 부서별 게시판, 앨범, 인스타 피드 연동
- **범위 제외:** 회원가입/로그인(일반 교인용), 온라인 헌금, 실시간 채팅, 교인 검색(요람)
